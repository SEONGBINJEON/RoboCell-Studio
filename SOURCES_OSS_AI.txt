4. 생성형 AI 활용 내역

개발 보조
OpenAI Codex를 코드 검토·구현·테스트 작성/실행·공식 자료 조사·UI 검토·
발표 초안과 파일 생성에 사용했습니다. 생성된 코드와 문서는 실행, 테스트,
브라우저 화면, 실제 로그를 대조해 검토했습니다.

제품 기능
Amazon Bedrock을 근거 기반 진단 보조에 연결합니다. 실행 요약과 이상징후,
입력의 가정을 문맥으로 전달하고 관측 사실·원인 후보·확인 절차를 구분합니다.
AI 응답은 안전 인증, 고장 원인의 확정, 설비 자동 제어 명령이 아닙니다.

시각 자료
최종 발표는 팀 원본16장에 자체 UI 캡처와 실제 Isaac Sim 보관 프레임을 추가했습니다.
생성형 이미지나 합성 장면을 실제 제조 현장 사진으로 제시하지 않았습니다.
공장 예시는 합성 또는 공개 공정 참고 재구성임을 표시합니다.

발표자료 생성 도구
OpenAI Artifact Tool로 팀 원본 PPTX를 불러와 텍스트와 이미지를 편집했습니다.
PDF는 동일한 슬라이드 렌더를 사용해 원본 배치와 글꼴 외관을 보존했습니다.
PPTX의 본문은 편집 가능하고 PDF는 발표용 고해상도 이미지 페이지입니다.
출처와 해석 한계는 발표자 노트와 이 문서에 보존합니다.
